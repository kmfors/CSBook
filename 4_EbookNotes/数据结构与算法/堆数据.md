## 堆数据结构详解

### 什么是堆？

**堆**是一种特殊的完全二叉树，满足以下性质：
- **完全二叉树**：除了最后一层，其他层节点都是满的，且最后一层节点靠左排列
- **堆序性**：任意节点的值与其子节点的值满足特定的大小关系

### 堆的两种类型

#### 最小堆（Min Heap）
```
父节点 <= 子节点
根节点是最小值

例子：
        1
      /   \
     3     5
    / \   /
   7   9 8
```

#### 最大堆（Max Heap）
```
父节点 >= 子节点
根节点是最大值

例子：
        9
      /   \
     7     5
    / \   /
   3   1 4
```

### 堆的存储方式

通常用**数组**存储，利用下标关系：
```
数组表示：[1, 3, 5, 7, 9, 8]
索引关系：
- 父节点索引 = (i - 1) / 2
- 左子节点索引 = 2 * i + 1  
- 右子节点索引 = 2 * i + 2

        1(0)
      /     \
     3(1)    5(2)
    /   \    /
   7(3) 9(4) 8(5)
```

### 核心操作及时间复杂度

| 操作         | 时间复杂度 | 描述                           |
| ------------ | ---------- | ------------------------------ |
| **获取最值** | O(1)       | 直接返回根节点                 |
| **插入**     | O(log n)   | 添加到末尾，上浮调整           |
| **删除最值** | O(log n)   | 删除根，末尾元素放根，下沉调整 |
| **建堆**     | O(n)       | 从最后一个非叶子节点开始下沉   |

### 基本操作实现

#### 上浮（用于插入）
```cpp
// 最小堆的上浮
void siftUp(vector<int>& heap, int i) {
    while (i > 0) {
        int parent = (i - 1) / 2;
        if (heap[parent] <= heap[i]) break;
        swap(heap[i], heap[parent]);
        i = parent;
    }
}
```

#### 下沉（用于删除）
```cpp
// 最小堆的下沉
void siftDown(vector<int>& heap, int i, int size) {
    while (true) {
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        int smallest = i;
        
        if (left < size && heap[left] < heap[smallest])
            smallest = left;
        if (right < size && heap[right] < heap[smallest])
            smallest = right;
            
        if (smallest == i) break;
        swap(heap[i], heap[smallest]);
        i = smallest;
    }
}
```

### 完整示例

```cpp
class MinHeap {
private:
    vector<int> heap;
    
    void siftUp(int i) {
        while (i > 0 && heap[(i-1)/2] > heap[i]) {
            swap(heap[i], heap[(i-1)/2]);
            i = (i-1)/2;
        }
    }
    
    void siftDown(int i) {
        int size = heap.size();
        while (true) {
            int left = 2*i + 1;
            int right = 2*i + 2;
            int smallest = i;
            
            if (left < size && heap[left] < heap[smallest])
                smallest = left;
            if (right < size && heap[right] < heap[smallest])
                smallest = right;
                
            if (smallest == i) break;
            swap(heap[i], heap[smallest]);
            i = smallest;
        }
    }
    
public:
    void push(int val) {
        heap.push_back(val);
        siftUp(heap.size() - 1);
    }
    
    int pop() {
        if (heap.empty()) throw exception();
        int minVal = heap[0];
        heap[0] = heap.back();
        heap.pop_back();
        if (!heap.empty()) siftDown(0);
        return minVal;
    }
};
```

### 应用场景

1. **优先队列** - 任务调度、进程管理
2. **堆排序** - O(n log n) 排序算法
3. **Top K 问题** - 找最大/最小的K个元素
4. **定时器管理** - 最早超时任务优先
5. **Dijkstra算法** - 最短路径
6. **Huffman编码** - 构建最优二叉树

### 堆排序示例

```cpp
void heapSort(vector<int>& arr) {
    // 建堆
    for (int i = arr.size()/2 - 1; i >= 0; i--)
        siftDown(arr, i, arr.size());
    
    // 排序
    for (int i = arr.size() - 1; i > 0; i--) {
        swap(arr[0], arr[i]);  // 最大元素放末尾
        siftDown(arr, 0, i);    // 对剩余元素重新堆化
    }
}
```

### 优缺点

**优点**：
- 快速获取最值（O(1)）
- 插入和删除操作效率高（O(log n)）
- 空间利用率高（数组存储）

**缺点**：
- 查找任意元素较慢（O(n)）
- 不支持高效的中位数查找
- 不适合需要频繁修改值的场景

堆是一种**简单但强大**的数据结构，在系统编程和算法设计中都有广泛应用！
