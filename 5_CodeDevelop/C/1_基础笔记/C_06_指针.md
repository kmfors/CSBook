# 指针

C 语言的 **指针（Pointer）** 是其最强大（也最容易出错）的特性之一，它允许直接操作内存地址，从而实现高效的数据处理、动态内存管理、函数回调等功能。以下是系统化的指针知识讲解：

---

## 指针的基本概念
### 什么是指针
- 指针是一个 **变量**，其值是另一个变量的 **内存地址**。
- 通过指针可以直接访问或修改目标变量的值。

### 指针的声明与初始化
```c
// 数据类型 *指针变量名;  // 声明指针
int num = 10;
int *ptr = &num;  // ptr指向num的地址
```
- `&`：取地址运算符（获取变量的内存地址）。
- `*`：解引用运算符（访问指针指向的值）。

---



## 指针的核心操作

### 访问指针指向的值
```c
printf("num的值: %d\n", *ptr);  // 输出: 10
```

### 修改指针指向的值
```c
*ptr = 20;  // 通过指针修改num的值
printf("num的新值: %d\n", num);  // 输出: 20
```

### 指针的算术运算
指针加减整数时，移动的步长取决于指向的数据类型大小（如 `int` 通常为 4 字节）：
```c
int arr[3] = {10, 20, 30};
int *p = arr;  // p指向arr[0]
printf("%d\n", *(p + 1));  // 输出: 20（p+1指向arr[1]）
```

---

## 指针与数组
### 数组名是指向首元素的指针
```c
int arr[3] = {1, 2, 3};
int *p = arr;  // 等价于 p = &arr[0]
```

### 通过指针遍历数组
```c
for (int i = 0; i < 3; i++) {
    printf("%d ", *(p + i));  // 输出: 1 2 3
}
```

### 指针与字符串
C 字符串本质是字符数组，常用指针操作：
```c
char str[] = "Hello";
char *ptr = str;
while (*ptr != '\0') {
    printf("%c", *ptr);  // 逐个字符输出
    ptr++;
}
```

---



## 指针与函数

### 指针作为函数参数（传址调用）
```c
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}
int main() {
    int x = 1, y = 2;
    swap(&x, &y);  // 交换x和y的值
}
```

### 返回指针的函数
```c
int* findMax(int *a, int *b) {
    return (*a > *b) ? a : b;
}
```

---



## 动态内存分配

使用指针管理堆内存（需 `#include <stdlib.h>`）：
### malloc 与 free
```c
int *p = (int*)malloc(5 * sizeof(int));  // 分配5个int的空间
if (p != NULL) {
    p[0] = 10;  // 使用内存
    free(p);    // 释放内存
}
```

### calloc 与 realloc
```c
int *p = (int*)calloc(5, sizeof(int));  // 分配并初始化为0
p = realloc(p, 10 * sizeof(int));       // 调整内存大小
```

## 指针的高级用法

### 指针数组 vs 数组指针
- **指针数组**：元素是指针的数组。
  ```c
  int *ptr_arr[3];  // 存储3个int指针
  ```
- **数组指针**：指向数组的指针。
  ```c
  int (*arr_ptr)[3];  // 指向包含3个int的数组
  ```

### 函数指针
指向函数的指针，用于回调或动态调用：
```c
int add(int a, int b) { return a + b; }
int main() {
    int (*func_ptr)(int, int) = add;  // 函数指针
    printf("%d\n", func_ptr(2, 3));   // 输出: 5
}
```

### 多级指针（指针的指针）
```c
int num = 10;
int *p = &num;
int **pp = &p;  // 二级指针
printf("%d\n", **pp);  // 输出: 10
```

---



## 常见指针错误

### 野指针（未初始化的指针）
```c
int *p;  // 未初始化
*p = 10; // 未定义行为（可能崩溃）
```

### 内存泄漏
```c
int *p = malloc(sizeof(int));
// 忘记free(p)导致内存泄漏
```

### 悬空指针（指向已释放的内存）
```c
int *p = malloc(sizeof(int));
free(p);
*p = 10;  // 错误！p已成为悬空指针
```

---



## 指针与结构体

### 访问结构体成员
```c
struct Point { int x; int y; };
struct Point p1 = {1, 2};
struct Point *ptr = &p1;
printf("%d\n", ptr->x);  // 输出: 1（等价于 (*ptr).x）
```

### 动态分配结构体
```c
struct Point *p = malloc(sizeof(struct Point));
p->x = 10;
free(p);
```

---



## 总结表：指针的核心要点

| **概念**         | **说明**                                         |
| ---------------- | ------------------------------------------------ |
| **指针的本质**   | 存储内存地址的变量                               |
| **声明与初始化** | `int *p = &var;`                                 |
| **解引用**       | `*p` 访问指向的值                                |
| **指针算术**     | `p + 1` 移动的字节数取决于数据类型               |
| **指针与数组**   | 数组名是首元素指针，`arr[i]` 等价于 `*(arr + i)` |
| **动态内存**     | `malloc`/`calloc` 分配，`free` 释放              |
| **函数指针**     | `int (*func)(int, int)` 定义函数指针             |
| **多级指针**     | `int **pp` 指向指针的指针                        |

掌握指针需要结合实践（如链表、文件操作等）。建议通过调试工具观察指针和内存的变化，以加深理解！
