# 函数

在 C 语言中，**函数（Function）** 是一段可重复使用的代码块，用于执行特定任务。函数可以接收输入参数、执行操作，并返回结果。合理使用函数可以提高代码的模块化、可读性和复用性。

---

## 函数的组成
一个 C 函数通常包括以下部分：
```c
返回值类型 函数名(参数列表) {
    // 函数体（执行代码）
    return 返回值; // 可选
}
```
示例如下：

```c
int add(int a, int b) {  // 函数定义
    return a + b;
}
```

---



## 函数的分类

### 标准库函数
C 语言内置的函数，直接调用即可（需包含头文件）：
- **输入/输出**：`printf()`, `scanf()`, `getchar()`
- **数学运算**：`sqrt()`, `pow()`（需 `#include <math.h>`）
- **字符串处理**：`strlen()`, `strcpy()`（需 `#include <string.h>`）

**示例**：

```c
#include <stdio.h>
#include <math.h>

int main() {
    double x = sqrt(25); // 调用数学库函数
    printf("平方根: %f\n", x);
    return 0;
}
```

### 用户自定义函数
由程序员自己编写的函数，例如：
```c
// 函数声明（可选，用于提前告知编译器）
int max(int a, int b); 

int main() {
    int result = max(10, 20); // 调用自定义函数
    printf("较大值: %d\n", result);
    return 0;
}

// 函数定义
int max(int a, int b) {
    return (a > b) ? a : b;
}
```

## 函数的声明与定义
- **声明（Declaration）**：告诉编译器函数的存在（参数和返回值类型），通常在头文件或文件顶部。
  ```c
  int add(int a, int b); // 声明
  ```
- **定义（Definition）**：实现函数的具体逻辑。
  ```c
  int add(int a, int b) { // 定义
      return a + b;
  }
  ```

## 函数的参数传递

### 值传递
函数接收参数的 **副本**，修改不影响原变量。

```c
void swap(int a, int b) { // 值传递
    int temp = a;
    a = b;
    b = temp;
}
int main() {
    int x = 1, y = 2;
    swap(x, y); // x和y的值不会交换
    printf("x=%d, y=%d\n", x, y); // 输出: x=1, y=2
}
```

### 指针传递
通过指针直接操作原变量。

```c
void swap(int *a, int *b) { // 指针传递
    int temp = *a;
    *a = *b;
    *b = temp;
}
int main() {
    int x = 1, y = 2;
    swap(&x, &y); // x和y的值交换
    printf("x=%d, y=%d\n", x, y); // 输出: x=2, y=1
}
```

## 函数的返回值

- 使用 `return` 返回结果，返回值类型需与函数声明一致。
- 如果函数无返回值，声明为 `void`。

```c
// 无返回值函数
void greet() {
    printf("Hello!\n");
}

// 有返回值函数
int square(int n) {
    return n * n;
}
```

---



## 递归函数

函数调用自身，适用于分治问题（如阶乘、斐波那契数列）。  

```c
// 计算阶乘
int factorial(int n) {
    if (n == 0) return 1;         // 终止条件
    else return n * factorial(n - 1); // 递归调用
}
int main() {
    printf("5! = %d\n", factorial(5)); // 输出: 120
}
```

## 函数的作用域规则

- **局部变量**：函数内部定义，仅在函数内有效。
- **全局变量**：函数外部定义，整个程序可见（需谨慎使用）。
- **静态变量**：用 `static` 修饰，生命周期延长至程序结束。
  
  ```c
  void counter() {
      static int count = 0; // 静态局部变量
      count++;
      printf("Count: %d\n", count);
  }
  int main() {
      counter(); // 输出: Count: 1
      counter(); // 输出: Count: 2（保留上次的值）
  }
  ```

## main() 函数
- 程序的入口函数，必须存在。
- 返回值 `0` 表示成功，非零表示错误。
  ```c
  int main(int argc, char *argv[]) { 
      // argc: 参数个数，argv: 参数数组
      printf("程序名: %s\n", argv[0]);
      return 0;
  }
  ```

---

## 函数指针
将函数地址赋值给指针，用于回调或动态调用。  
**示例**：

```c
int add(int a, int b) { return a + b; }
int main() {
    int (*func_ptr)(int, int) = &add; // 函数指针
    int result = func_ptr(3, 5);     // 通过指针调用
    printf("结果: %d\n", result);     // 输出: 8
}
```

## **总结**
| 要点         | 说明                                    |
| ------------ | --------------------------------------- |
| **函数定义** | `返回值类型 函数名(参数) { ... }`       |
| **参数传递** | 值传递（副本）、指针传递（修改原值）    |
| **返回值**   | 通过 `return` 返回，`void` 表示无返回值 |
| **递归**     | 函数调用自身，需有终止条件              |
| **作用域**   | 局部变量（函数内）、全局变量（程序内）  |
| **main()**   | 程序入口，可接收命令行参数              |
