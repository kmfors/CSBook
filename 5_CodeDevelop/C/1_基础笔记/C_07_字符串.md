# C 语言字符串

C 语言中的字符串是一种非常重要的数据类型，虽然 C 语言本身并没有专门的 "字符串类型"，但通过字符数组和指针的方式实现了字符串功能。下面我将全面讲解 C 语言的字符串知识。

## 字符串的基本概念

### 什么是字符串
- 在 C 语言中，字符串是以空字符 `'\0'`（ASCII 码为 0）结尾的字符序列
- 字符串实际上是一维字符数组
- 字符串常量用双引号括起来，如 `"Hello"`

### 字符串的存储方式
```c
char str[] = "Hello";  // 实际存储：'H','e','l','l','o','\0'
```
- 编译器会自动在字符串末尾添加 `'\0'`
- 数组长度比字符串长度多 1（因为包含 `'\0'`）



## 字符串的声明和初始化

### 字符数组方式
```c
// 方式1：指定大小并初始化
char str1[10] = "Hello";

// 方式2：不指定大小，由初始化内容决定
char str2[] = "World";

// 方式3：逐个字符初始化
char str3[] = {'H','e','l','l','o','\0'};
```

### 字符指针方式
```c
char *str_ptr = "Hello";  // 字符串常量存储在只读区域
```



## 字符串的输入输出

### 输出写字符串

`printf` 函数会逐个写字符串中的字符，直到遇到空字符。(如果字符数组中没有空字符， `printf` 会一直写，直到在内存的某个位置找到空字符为止)。

如果只想显示字符串的一部分，可以使用转换说明 `%.ps` ，这里 `p` 是要显示的字符数量，如：

```c
printf("%.6s\n", str);
```

字符串跟整数一样，可以在指定的字段内显示。转换说明 **%ms 会在大小为 m 的字段内显示字符串**。(对于超过 m 个字符的字符串， `printf` 会显示整个字符串，不会截断)。

- 如果字符串少于 m 个字符，则会在字段内右对齐。
- 如果要左对齐，可以在 m 前加一个减号。

C 函数库还提供了 `puts` 函数，用来输出字符串

```c
printf("%s\n", str);  // 基本输出
// 二者等价
puts(str);  // 自动添加换行符
```

### 输入读字符串

读字符串时， **`scanf` 会跳过前面的空白字符，然后读入字符并存储到指定地址中，直到遇到空白字符为止**。

- `scanf` 始终会在字符串末尾存储一个空字符。
- 用 `scanf` 读入的字符串永远不会包含空白字符。

因此， `scanf` 通常不会读入一整行输入。空格符和制表符会使 `scanf` 停止读入。

为了读入一整行输入，可以使用 `gets` 函数。类似于 `gets` 会把读入的字符存储到 **字符数组** 中，然后存储一个空字符。然而不同的是：

- `gets` 不会跳过前面的空白字符 (`scanf` 会跳过)
- `gets` 会一直读入直到遇到换行符才停止 (`scanf` 会在任意空白字符处停止)
- `gets` 函数会忽略掉换行符，用空字符代替换行符

```c
char name[20];

// 使用scanf（不安全，可能缓冲区溢出）
scanf("%s", name);  // 遇到空格会停止

// 使用gets（已被弃用，不安全）
gets(name);  // 读取整行，但不检查长度

// 使用fgets（推荐）
fgets(name, sizeof(name), stdin);  // 安全，会保留换行符
```

> [!NOTE]
>
> - `scanf` 和 `gets` 都不会检查数组是否越界。因此，使用这两类函数是不安全的。





## 常用字符串处理函数

### 字符串长度
```c
#include <string.h>

size_t len = strlen(str);  // 不包含'\0'
```

### 字符串复制
```c
strcpy(dest, src);  // 不安全，可能溢出
strncpy(dest, src, n);  // 较安全，复制最多n个字符
```

### 字符串连接
```c
strcat(dest, src);  // 将src追加到dest末尾
strncat(dest, src, n);  // 最多追加n个字符
```

### 字符串比较
```c
int result = strcmp(str1, str2);
// 返回值：
// <0 str1小于str2
// =0 str1等于str2
// >0 str1大于str2

strncmp(str1, str2, n);  // 比较前n个字符
```

### 字符串查找
```c
char *p = strchr(str, 'l');  // 查找字符第一次出现的位置
char *p = strrchr(str, 'l'); // 查找字符最后一次出现的位置
char *p = strstr(str, "ll"); // 查找子串
```



## 字符串与指针

### 指针操作字符串
```c
// 遍历字符串里的字符
char *ptr = "Hello";
while(*ptr != '\0') {
    printf("%c", *ptr);
    ptr++;
}
```

### 字符串数组
```c
// 二维字符数组
char names[3][10] = {"Alice", "Bob", "Charlie"};

// 指针数组（更高效）
char *names[] = {"Alice", "Bob", "Charlie"};
```



## 字符串与内存

### 动态分配字符串
```c
char *str = malloc(20 * sizeof(char));
strcpy(str, "Dynamic string");
// 使用完后
free(str);
```

### 常见错误
```c
// 错误1：忘记分配内存
char *str;
strcpy(str, "Hello");  // 段错误

// 错误2：缓冲区溢出
char str[5];
strcpy(str, "Hello World");  // 溢出

// 错误3：修改字符串常量
char *p = "Hello";
p[0] = 'h';  // 未定义行为
```



## 常用字符串函数

### 获取字符串长度
```c
// - 返回字符串str的长度（第一个空字符'\0'之前的字符个数）
size_t strlen(const char *str);
```
示例如下：

```c
int len;
len = strlen("abc");  // len = 3
len = strlen("");     // len = 0
char str1[] = "abc";
len = strlen(str1);   // len = 3
```

### 字符串拷贝
```c
char *strcpy(char *dest, const char *src);
```
- 将 src 字符串复制到 dest 指向的数组中
- 会复制直到遇到 src 的第一个空字符（包括空字符）
- 返回目标字符串指针 dest

示例如下：

```c
char str2[10];
strcpy(str2, "abcd");  // str2 = "abcd"
```

> [!NOTE]
>
> **安全风险**：不检查目标数组大小，可能导致缓冲区溢出。
>
> **更安全的替代方案**：
>
> ```c
> strncpy(dest, src, sizeof(dest));  // 限制复制的字符数
> // 或者
> strncpy(dest, src, sizeof(dest)-1);
> dest[sizeof(dest)-1] = '\0';
> ```



### 字符串连接

```c
char *strcat(char *dest, const char *src);
```
- 将 src 字符串追加到 dest 字符串末尾
- 返回目标字符串指针 dest

示例如下：

```c
char str1[100] = "Hello";
strcat(str1, " world!");  // str1 = "Hello world!"
```

> [!NOTE]
>
> **安全风险**：不检查目标数组剩余空间。
>
> **更安全的替代方案**：
>
> ```c
> strncat(dest, src, sizeof(dest)-strlen(dest)-1);  // 预留空间给空字符
> ```



### 字符串比较
```c
int strcmp(const char *str1, const char *str2);
```
- 按字典顺序比较 str1 和 str2
- 返回值：
  - 负数：`str1 < str2`
  - 0：`str1 == str2`
  - 正数：`str1 > str2`

示例如下：

```c
if(strcmp(str1, str2) < 0) {
    // str1 < str2
}
```

### 字符串分割
```c
#include <string.h>
#include <stdio.h>

int main() {
    char str[] = "one,two,three";
    char *token = strtok(str, ",");
	// 以逗号为分隔符，分割字符串
    while (token != NULL) {
        printf("%s\n", token);
        token = strtok(NULL, ",");
    }
    return 0;
}
```

### 字符串转换
```c
// 字符串转数字
int num = atoi("123");  // ASCII to integer
double d = atof("3.14"); // ASCII to float

// 数字转字符串
char buffer[20];
sprintf(buffer, "%d", 123);  // 整数转字符串
```



## 安全字符串处理

### 安全版本函数
```c
strcpy_s(dest, dest_size, src);  // 安全复制
strcat_s(dest, dest_size, src);  // 安全连接
```

### 使用更安全的函数
```c
snprintf(buffer, sizeof(buffer), "%s", str);  // 安全格式化
```



## 总结

C 语言字符串要点：
1. 字符串以'\0'结尾的字符数组形式存储
2. 可以使用字符数组或字符指针处理字符串
3. string.h 提供了丰富的字符串处理函数
4. 要注意字符串操作的安全性，防止缓冲区溢出
5. 动态字符串需要手动管理内存
6. 字符串常量存储在只读区域，不可修改

掌握这些知识后，你就能在 C 程序中高效、安全地处理字符串了。
