# 结构、联合和枚举

## 结构体

### 基本使用

结构体是C语言中用于将不同类型的数据组合成一个整体的复合数据类型。

```c
struct Student {
    char name[50];
    int age;
    float score;
};
```

1. **声明结构体变量**:
   ```c
   struct Student stu1;
   ```

2. **初始化**:
   ```c
   struct Student stu2 = {"张三", 20, 85.5};
   ```

3. **访问成员**:
   ```c
   strcpy(stu1.name, "李四");
   stu1.age = 21;
   stu1.score = 90.0;
   ```

4. **结构体指针**:
   ```c
   struct Student *pStu = &stu1;
   pStu->age = 22;  // 等价于 (*pStu).age = 22;
   ```

### 对齐规则

1. **首地址对齐**
   结构体变量的**起始地址**必须是其内部**最宽基本类型成员大小**的整数倍。
   - *示例*：若最宽成员是 `double` (8字节)，则结构体首地址必须是8的倍数。
2. **成员偏移量对齐**
   每个成员相对于结构体首地址的**偏移量**必须是**该成员自身大小**的整数倍。若不满足，编译器在成员间插入填充字节（Padding）。
   - *公式*：`offset % sizeof(member) == 0`
   - *示例*：`int` 成员偏移量必须是4的倍数。
3. **结构体总大小对齐**
   结构体的**总大小**必须是**最宽基本类型成员大小**的整数倍。若不满足，编译器在末尾添加填充字节。
   - *示例*：若最宽成员是4字节，结构体总大小必须是4的倍数。
4. **连续相同类型成员**
   类型相同的连续成员会分配到连续内存空间（类似数组），**不插入填充**。
   - *示例*：`char a; char b;` 始终相邻存储。
5. **处理器位数的影响**
   - 若成员大小 > 处理器位数（如32位系统下 `double` 8字节），以**处理器位数为对齐单位**。
   - 否则，以**结构体中最宽基本类型成员**为对齐单位。
   - *32位系统示例*：对齐单位 = min(8字节, 处理器位数4字节) → 按4字节对齐。

## 联合

联合是一种特殊的数据类型，允许在相同的内存位置存储不同的数据类型。

### 基本语法

```c
union Data {
    int i;
    float f;
    char str[20];
};
```

### 使用方式

```c
union Data data;
data.i = 10;       // 现在使用i成员
printf("%d\n", data.i); // 10

data.f = 220.5;     // 现在使用f成员，i的值被覆盖
printf("%f\n", data.f); // 220.500000
```

### 特点
- 所有成员共享同一块内存空间
- **联合的大小等于最大成员的大小**
- **同一时间只能使用一个成员**
- 常用于节省内存或实现变体记录

## 枚举

枚举是一种用户定义的类型，用于定义一组命名的整数常量。

### 基本语法

```c
enum Weekday {Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday};
```

### 使用方式

```c
enum Weekday today = Wednesday;

if (today == Wednesday) {
    printf("今天是周三\n");
}
```

### 特点
- 枚举常量默认从0开始，依次递增
- 可以显式指定值: `enum Color {Red=1, Green=5, Blue=10};`
- 提高代码可读性
- 本质上是整型常量

## 三者的比较

| 特性         | 结构体(struct)   | 联合(union)            | 枚举(enum)               |
| ------------ | ---------------- | ---------------------- | ------------------------ |
| 存储方式     | 各成员独立存储   | 共享存储空间           | 不占存储空间(编译时确定) |
| 内存占用     | 所有成员大小之和 | 最大成员大小           | 通常为int大小            |
| 用途         | 组合不同类型数据 | 同一时间只存储一种类型 | 定义一组相关常量         |
| 同时访问成员 | 可以             | 不可以                 | 不适用                   |

## 实际应用示例

```c
#include <stdio.h>
#include <string.h>

// 枚举示例
enum DeviceType {MOBILE, TABLET, LAPTOP, DESKTOP};

// 结构体示例
struct DeviceInfo {
    char model[50];
    int year;
    enum DeviceType type;
};

// 联合示例
union Price {
    float dollar;
    int euro;
};

int main() {
    // 使用枚举
    enum DeviceType myDevice = LAPTOP;
    
    // 使用结构体
    struct DeviceInfo device1;
    strcpy(device1.model, "MacBook Pro");
    device1.year = 2020;
    device1.type = myDevice;
    
    // 使用联合
    union Price price;
    price.dollar = 999.99;
    printf("Price in dollars: %.2f\n", price.dollar);
    
    price.euro = 899;
    printf("Price in euros: %d\n", price.euro);  // 之前存储的dollar值被覆盖
    
    return 0;
}
```

这些复合数据类型是C语言中组织和管理复杂数据的重要工具，合理使用它们可以大大提高代码的可读性和可维护性。
