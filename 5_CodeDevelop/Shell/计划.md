以下是一份系统学习 Shell（以 Bash 为主）的计划，分为 **基础 → 进阶 → 实战** 三个阶段。建议每天投入 1–2 小时，4–6 周完成。每个阶段都配有练习题和项目，确保学以致用。

---

## 第一阶段：基础入门（1–2 周）
**目标**：熟悉 Linux 常用命令，能编写简单的脚本。

### 1. 环境准备
- [x] 安装 Linux（虚拟机 / WSL / 云服务器）或 macOS 终端。
- [x] 熟悉终端基本操作：`pwd`, `cd`, `ls`, `mkdir`, `rm`, `cp`, `mv`, `cat`, `less`, `head`, `tail`。

### 2. 核心命令
- [x] 文件权限：`chmod`, `chown`, `umask`
- [x] 文本处理：`echo`, `grep`, `sed`, `awk`（基础用法）
- [ ] 管道 `|` 和重定向 `>`, `>>`, `<`
- [ ] 进程管理：`ps`, `top`, `kill`, `jobs`, `fg`, `bg`

### 3. 脚本基础
- 创建并执行脚本：`#!/bin/bash`，`chmod +x`，`./script.sh`
- 变量与引用：`var=value`，`$var`，`${var}`，单双引号区别
- 特殊变量：`$0`, `$1`, `$#`, `$@`, `$?`, `$$`
- 算术运算：`$(( ... ))`，`let`
- 输入输出：`read`，`printf`

### 4. 控制结构
- 条件测试：`test` 或 `[ ]`，`[[ ]]`（推荐）
- `if-then-else-elif-fi`
- `case` 语句
- 循环：`for`, `while`, `until`, `break`, `continue`

### 5. 第一阶段练习
- 编写脚本备份指定目录（tar + 时间戳）。
- 用 `grep` 和 `awk` 从日志中提取特定行和字段。
- 写一个猜数字游戏（`while` 循环 + `$RANDOM`）。

**推荐资源**：
- 《鸟哥的 Linux 私房菜》第 10–13 章
- Bash 官方手册：`man bash`
- 在线练习：Linux Journey（命令行部分）

## 第二阶段：进阶技巧（1–2 周）
**目标**：掌握函数、数组、字符串处理、调试、正则表达式。

### 1. 函数与作用域
- 定义函数：`function f() { ... }` 或 `f() { ... }`
- 局部变量 `local`
- 返回值（退出码）与 `return`

### 2. 数组与关联数组
- 索引数组：`arr=(a b c)`，`${arr[@]}`
- 关联数组（Bash 4+）：`declare -A map`，`map["key"]=value`

### 3. 字符串操作
- 子串：`${var:offset:length}`
- 替换：`${var/old/new}`，`${var//old/new}`
- 删除匹配模式：`${var#pattern}`，`${var%pattern}`

### 4. 正则表达式与文本处理
- `grep -E` / `egrep`，`sed` 高级替换，`awk` 字段处理
- 结合 `[[ string =~ regex ]]`

### 5. 脚本调试与安全
- 调试模式：`bash -x script.sh`，`set -x` / `set +x`
- 错误处理：`set -e`（遇错退出），`set -u`（未定义变量报错）
- 信号捕获：`trap` 清理临时文件

### 6. 进阶练习
- 写一个脚本监控 CPU/内存使用率，超过阈值发送警告（可用 `mail` 或写入日志）。
- 批量重命名文件（支持正则匹配替换）。
- 用关联数组统计文本中单词出现频率。

**推荐资源**：
- 《Advanced Bash-Scripting Guide》（ABS）
- Bash Hackers Wiki
- `explainshell.com`（解释命令）

## 第三阶段：实战与生态（1–2 周）
**目标**：能编写健壮的工具脚本，集成系统任务，了解 Shell 的边界。

### 1. 文件系统与 I/O
- 文件描述符：`exec 3<> file`，重定向到子 shell
- 临时文件：`mktemp`
- 读取 CSV/配置文件

### 2. 子 shell 与进程替换
- `( cmd1; cmd2 )` 子 shell
- 进程替换：`<(cmd)`，`>(cmd)`

### 3. 作业调度与自动化
- `cron` / `systemd timer` 定时任务
- `at` 单次计划任务
- `nohup` / `disown` 后台持久化

### 4. Shell 与其它语言交互
- 调用 Python/Perl 一行命令
- 解析 JSON：`jq` 命令
- 生成复杂数据：`printf`, `paste`, `join`

### 5. 编写健壮脚本的最佳实践
- 脚本头模板：`set -euo pipefail`
- 使用 `shellcheck` 静态检查
- 命令行参数解析：`getopts` 或 `getopt`
- 日志函数（带时间戳和级别）

### 6. 实战项目（任选 2–3 个）
- **日志分析器**：统计 Nginx 访问日志中 IP 访问次数、响应码占比。
- **系统健康检查脚本**：检查磁盘使用率、僵尸进程、开放端口，生成 HTML 报告。
- **部署脚本**：自动拉取 Git 仓库、安装依赖、重启服务（支持回滚）。
- **数据备份 + 清理**：保留最近 7 天备份，上传到云存储（如通过 `rclone`）。

**推荐资源**：
- 《The Linux Command Line》（William Shotts）
- Google Shell Style Guide（规范）
- 工具：`shellcheck`, `shfmt`, `bashdb`（调试器）

## 持续提升（学习计划之外）
- **阅读他人脚本**：从 GitHub 搜索 `.sh` 仓库（如 `awesome-bash`）。
- **贡献开源**：修复或改进简单脚本。
- **替代工具**：了解 `zsh`、`fish` 特色；何时不应使用 Shell（性能、复杂逻辑 → Python/Go）。
- **认证**：LPIC-1 中的 Shell 部分。

## 每日学习建议
- **早上（15分钟）**：复习昨天的一个命令或语法。
- **白天（30分钟）**：看书/教程，做笔记。
- **晚上（30–60分钟）**：动手写代码，完成练习题或小项目。
- **周末**：做一个小型实战项目，总结发布到博客或笔记。

> ⚠️ 避免陷阱：不要在脚本中用无引号的变量（容易出错），优先使用 `[[ ]]` 而非 `[ ]`，学会看错误信息并用 `set -x` 调试。

按此计划执行，一个月后你将具备独立编写和维护生产级 Shell 脚本的能力。祝你学习顺利！
