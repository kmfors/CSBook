## 1. 结构化绑定
**一句话**：把 pair、tuple、struct 的成员直接拆成独立变量。

```cpp
#include <iostream>
#include <map>

int main() {
    std::map<int, std::string> m = {{1, "a"}, {2, "b"}};

    // 以前：it->first, it->second
    for (const auto& [key, value] : m) {
        std::cout << key << " -> " << value << '\n';
    }

    // 也适用于函数返回 pair/tuple
    auto getPoint = []() -> std::pair<int, int> { return {3, 4}; };
    auto [x, y] = getPoint();
    std::cout << "x=" << x << ", y=" << y << '\n';
}
```

## 2. if / switch 初始化语句
**一句话**：在 `if` 或 `switch` 的条件里定义一个仅在该作用域有效的变量。

```cpp
#include <iostream>
#include <map>

int main() {
    std::map<int, std::string> m;

    // 传统写法：需要在外面声明 iter
    // if (auto it = m.find(1); it != m.end()) { ... }

    if (auto it = m.find(1); it != m.end()) {
        std::cout << "found: " << it->second << '\n';
    } else {
        std::cout << "not found\n";
    } // it 在这里就销毁了
}
```

## 3. 内联变量
**一句话**：头文件中定义全局变量，不违反 ODR（One Definition Rule）。

主要解决的问题：

- 重复定义：如果在多个 `.cpp` 文件里引入同一个头文件，链接时会报 `global_count` **重复定义** 的错误。
  - 原因：每个 `.cpp` 独立编译后都会产生一个 `global_count` 的定义，链接器不知道该用哪个。
  - 传统解决方案：
    1. 使用 `extern` 在头文件声明，定义放在具体 `.cpp` 文件中。*问题：麻烦，需要维护两个文件。*
    2. 使用 `static` 声明全局变量。*问题：每个 `.cpp` 有自己的副本，不是真正的全局变量。*



内联变量的规则：

1. **允许多次定义**：在多个 `.cpp` 里出现同一个内联变量定义，链接器会合并
2. **地址在所有翻译单元中相同**：`&global_count` 在不同 `.cpp` 里得到相同地址

```cpp
// my_math.h
#pragma once

inline int global_counter = 0;  // 多个 .cpp include 也不会重复定义

struct Config {
    static inline std::string name = "default"; // 不用再去 .cpp 里定义
};
```

## 4. std::optional
**一句话**：表示“可能有值，也可能没有”，不用搞特殊值（如 -1 表示无效）。

```cpp
#include <optional>
#include <iostream>

int main() {
    std::optional<int> opt = 42;
    
    // 方法1：* 解引用（不检查，危险）
    std::cout << *opt << '\n';  // 42
    
    // 方法2：value()（会抛异常）
    std::cout << opt.value() << '\n';  // 42
    
    // 方法3：value_or()（提供默认值）
    std::optional<int> empty;
    std::cout << empty.value_or(999) << '\n';  // 999（因为空）
    
    // 方法4：先检查再访问（最安全）
    if (opt.has_value()) {
        std::cout << opt.value() << '\n';
    }
    
    // 方法5：if 直接判断（推荐）
    if (opt) {  // 等价于 has_value()
        std::cout << *opt << '\n';
    }
}
```

## 5. std::variant
**一句话**：类型安全的 union，存 int、string、double 等有限几种类型之一。

- variant: 要么是 int，要么是 float，要么是 string（只存一个）
- tuple: 同时有 int、float、string（存三个）

```cpp
#include <iostream>
#include <variant>
#include <tuple>

int main() {
    // variant: 要么是 int，要么是 float，要么是 string（只存一个）
    std::variant<int, float, std::string> v;
    v = 42;           // 现在只有 int
    v = 3.14f;        // 覆盖，现在只有 float（int 丢了）
    v = "hello";      // 覆盖，现在只有 string（float 丢了）
    
    // tuple: 同时有 int、float、string（存三个）
    std::tuple<int, float, std::string> t(42, 3.14f, "hello");
    // 三个值同时存在，都能访问
    std::cout << std::get<0>(t) << '\n';  // 42
    std::cout << std::get<1>(t) << '\n';  // 3.14
    std::cout << std::get<2>(t) << '\n';  // "hello"
}
```

## 6. std::string_view
**一句话**：不拷贝字符串，只“看一眼”别人的字符串（高效传参）。

```cpp
#include <iostream>
#include <string_view>

void print_prefix(std::string_view sv) {
    if (sv.size() >= 3)
        std::cout << sv.substr(0, 3) << '\n';  // 不会拷贝
}

int main() {
    std::string s = "hello world";
    print_prefix(s);               // 自动转换
    print_prefix("abcde");         // 也支持字面量
    print_prefix(std::string_view("xyz"));
}
```

## 7. 折叠表达式（Fold expressions）
**一句话**：C++17 让你对变参模板的包直接做 `+`、`&&`、`||` 等运算。

```cpp
#include <iostream>

// 求和（二元左折叠）
template<typename... Args>
auto sum(Args... args) {
    return (args + ...);   // 展开成 ((a+b)+c)+...
}

// 检查是否全部大于 0
template<typename... Args>
bool all_positive(Args... args) {
    return (args > 0 && ...);  // (a>0) && (b>0) && ...
}

int main() {
    std::cout << sum(1, 2, 3, 4) << '\n';        // 10
    std::cout << all_positive(1, 5, 3) << '\n';  // 1 (true)
    std::cout << all_positive(1, -2, 3) << '\n'; // 0
}
```

## 8. constexpr lambda
**一句话**：lambda 也可以在编译期计算。

```cpp
#include <iostream>

int main() {
    constexpr auto add = [](int a, int b) { return a + b; };
    constexpr int result = add(3, 4);  // 编译期就算好了
    static_assert(result == 7);

    // lambda 里也能用 constexpr
    constexpr auto square = [](int x) constexpr { return x * x; };
    int arr[square(5)] = {};  // 编译期确定数组大小
    std::cout << sizeof(arr) / sizeof(int) << '\n';  // 25
}
```

## 9. 嵌套命名空间（Nested namespace）
**一句话**：不用写一长串 `namespace A { namespace B { ... }}`。

```cpp
// 以前
namespace A {
    namespace B {
        void f() {}
    }
}

// C++17
namespace A::B {
    void g() {}
}

int main() {
    A::B::g();
}
```

## 10. std::apply
**一句话**：把 tuple 的每个元素作为参数传给函数。

```cpp
#include <iostream>
#include <tuple>

void print(int a, double b, const char* c) {
    std::cout << a << ", " << b << ", " << c << '\n';
}

int main() {
    auto t = std::make_tuple(42, 3.14, "hello");
    std::apply(print, t);  // 相当于 print(42, 3.14, "hello")
}
```
