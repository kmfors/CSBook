## 概念介绍

`shared_ptr` 是一个 **共享所有权** 的智能指针，在语法上模拟了值语义的便捷性。它不是深拷贝，而是通过引用计数共享同一对象。

`shared_ptr` 包含两个部分：

- **原始指针**：指向实际管理的对象
- **控制块**：包含引用计数和其他管理信息（通常包含强引用计数、弱引用计数等）

**引用计数机制**：当新的 `shared_ptr` 被创建并指向同一对象时，引用计数增加；当 `shared_ptr` 被销毁或重置时，引用计数减少；当引用计数降为 0 时，自动删除管理的对象

**控制块的生命周期独立于管理的对象**：

- 第一个创建指向某对象的 `shared_ptr` 时分配控制块
- 最后一个引用（包括 `shared_ptr` 和 `weak_ptr`）被销毁时释放控制块

## 操作说明

最安全的分配和使用动态内存的方法是：调用一个名为 `make_shared` 的标准库函数。此函数在堆上分配对象并初始化，返回一个管理该对象的 `shared_ptr`。

使用 `make_shared` 时，必须指定要指定创建对象的类型。

```c++
// 
std::shared_ptr<int> sp1(new int(10)); // 1. 包裹 new 操作符

auto sp2 = std::make_shared<int>(42); // 2. 使用 make_shared 函数

// 获取对象本身
cout << "*sp2 = " << *sp2 << endl;		
// 获取对象原始指针
cout << "sp2.get() = " << sp2.get() << endl;
// 获取对象引用计数
cout << "sp2.use_count() = " << sp.use_count() << endl;
// 重置丢弃引用
sp2.reset();
```

| 特性           | `make_shared`            | `shared_ptr(new T)`  |
| :------------- | :----------------------- | :------------------- |
| **分配次数**   | 1 次                     | 2 次                 |
| **内存布局**   | 对象和控制块单块连续内存 | 对象和控制块分开分配 |
| **缓存友好性** | 更好（局部性原理）       | 较差                 |

技术细节：

- `make_shared`：通过单次分配同时获得对象内存和控制块内存
- `shared_ptr(new T)`：先 `new T` 分配对象内存，再在 `shared_ptr` 构造函数中分配控制块





## 缺陷问题

`shared_ptr` 的典型缺陷：循环引用，两个或多个对象通过`shared_ptr`相互引用，形成一个引用环，导致它们的引用计数永远不会降为0，从而无法自动释放内存。

![20240714215320](/1_store/1_asset/20240714215320.png)


循环引用导致的原因是 shared_ptr 是强引用的智能指针，每一次指向都会使得引用计数进行累加。但是单独的靠智能指针这种栈对象的销毁又不能将引用计数减为 0，所以就会出现循环引用而不能完成空间回收的问题。

解决方式：需要有一种弱引用的智能指针，可以执行空间，但是不会将引用计数累加，这样的一种指针叫做 `weak_ptr`。互相引用的两个 `shared_ptr` 需要使得其中一个改为 `weak_ptr`，但不会增加引用计数，可以利用对象的销毁而打破引用计数减为 0 的问题。

## 补充说明

`shared_ptr` 的析构函数会递减它所指向的对象的引用计数。如果引用计数变为 0，`shared_ptr` 的析构函数就会销毁对象，并释放它占用的内存。

`shared_ptr` 的构造函数是 `explicit` 的。因此不能将一个内置指针隐式转换为一个智能指针，必须使用直接初始化形式。

```c++
shared_ptr<int> p1 = new int(1024); // 错误！

shared_ptr<int> p2(new int(1024));  // 正确！
```

一个返回 `shared_ptr` 的函数不能在其返回语句中隐式转换一个普通指针：

```c++
shared_ptr<int> clone(int p){
    return new int(p); // 错误：隐式转换为shared_ptr<int>
}

// 必须将shared_ptr显式绑定到返回的指针上
shared_ptr<int> clone(int p){
    return shared_ptr<int>(new int(p)); // 正确
}
```
