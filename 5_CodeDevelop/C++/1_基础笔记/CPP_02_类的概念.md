## 类与对象

- 类是对现实世界中相似事物的抽象；对象是类的实例化结果。
- 类是抽象模板，定义事物的共性和规则；对象是具体实体，保存实际数据并执行操作。
- 类是静态的代码结构；对象是动态的运行实体。

### 类与对象的关系

- 类的本质：是逻辑上的抽象模板，不占用内存，用于定义对象的属性和行为规则。

- 对象的本质：是类的具体实例，占用内存空间，基于类的模板创建具体的实体。

总结：类定义后不分配内存，对象创建时会分配内存。

### 类的声明与定义

类的声明通常使用 `class` 关键字，而类的定义则需要在类体中定义相关的具体代码。

类的定义包括：

- 数据成员（属性）：描述对象的特征
- 成员函数（方法）：定义对象的行为
- 访问控制符（`public`、`private`、`protected`）：控制数据的可见性和安全性。



## 访问控制

C++类中成员的访问权限分为三种：

- `public`：类内、类外均可访问，用于定义类的对外接口（公有方法）
- `private`：仅类内成员函数和友元（`friend`）可访问，用于隐藏数据或内部实现细节
- `protected`：类内、派生类中可访问，用于继承体系中共享成员（基类设计）

`class` 关键字定义的类：默认成员为 `private`。

`struct` 关键字定义的结构体：默认成员为 `public`。



## 对象的创建

在 C++ 中，类对象的创建是类的实例化过程，通过调用 **构造函数** 完成内存分配和成员初始化。

对象创建分为三个阶段：

1. 内存分配：编译器为对象分配内存空间（栈或堆），此时对象处于未初始化状态。
2. 调用构造函数：调用匹配的构造函数，完成数据成员的初始化和资源分配。
3. 对象生命周期的开始：构造函数执行完毕后，对象正式可用。

### 构造函数

构造函数是类的特殊成员函数，负责以下任务：

1. 初始化数据成员，确保对象创建时成员变量处于合法状态。
2. 资源分配，例如动态内存的申请、文件打开等。
3. 参数校验，验证输入参数的合法性，避免无效状态。

构造函数有以下特点：

- 构造函数名与类名相同
- 没有返回值，也不用 void
- 允许多个参数，允许重载

构造函数有多个不同类型，主要有：默认构造、参数化构造、拷贝构造、移动构造。

### 默认构造函数

默认构造函数又称无参构造函数，即创建对象时不提供参数。**如果我们并未显式定义任何构造函数，编译器将自动生成一个默认的构造函数。**

```c++
class MyClass {
public:
    MyClass() { // 默认构造函数
        // 初始化逻辑
    }
};
```

### 有参构造函数

通过参数初始化对象

```c++
class MyClass {
public:
    MyClass(int num = 10)
    	: m_num(num) {}
private:
    int m_num;
};
```



### 拷贝构造函数

用同类型对象初始化新对象（深拷贝防止资源重复释放）。

### 移动构造函数

高效转移资源（如动态内存），避免深拷贝开销。



## 对象的销毁

对象销毁过程分为两个阶段：

- 析构函数的调用
  - 调用对象的析构函数（用户定义或编译器生成）。
  - 清理动态分配的资源（如 `delete` 堆内存、关闭文件等）
- 内存回收
  - **栈对象**：栈内存由系统自动回收。
  - **堆对象**：`delete` 操作释放堆内存。

### 析构函数

在 C++ 中，析构函数是类的特殊成员函数，用于在对象生命周期结束时自动释放资源（如内存、文件句柄、网络连接等）。其核心作用是 **逆向执行构造函数的工作**，确保资源安全清理，避免内存泄漏。

析构函数的关键特性：

1. **命名规则**：`~类名()`，无参数、无返回值。
2. **自动调用**：由编译器触发，无需手动调用。
3. **不可重载**：一个类只能有一个析构函数。
4. **继承体系中的虚析构**：若类可能被继承，基类析构函数应声明为 `virtual`，否则通过基类指针删除派生类对象时，派生类资源无法释放。

析构函数的调用时机：（我们可以针对以下的三种情形设计代码验证）

1. 栈对象（局部），程序流程到达该对象的定义处就调用构造函数，在程序离开栈对象的作用域时自动调用析构函数。
2. 全局/静态对象，当程序流程第一次到达该对象定义处调用构造函数，在整个程序结束时调用析构函数。
3. **堆对象**，每当创建该对象时调用构造函数，必须要 **手动的执行 delete 操作**，才能调用析构函数。

```c++
class MyClass(){
    ~MyClass() {
		std::cout << "~MyClass() execute" << std::endl;
	}
};
```

**析构函数使用的核心原则**：

- 管理资源的类必须定义析构函数。
- 基类析构函数应为虚函数。
- 优先使用 RAII 模式管理资源。

### 销毁顺序

1. 成员变量的销毁顺序

- **逆初始化顺序**：按成员变量在类中声明的 **相反顺序** 调用析构函数。

2. 继承体系中的销毁顺序

- **派生类析构 → 基类析构**（与构造函数顺序相反）。

## this 指针

C++ 中的 `this` 指针是一个隐式参数，它在类的 **非静态成员函数** 中 **自动可用**，用于指向调用该函数的对象实例。

- `this` 是一个指针，指向调用成员函数的对象实例。通过 `this` 可以访问当前对象的所有成员（变量和函数）。
- 编译器在编译成员函数时，自动将 `this` 作为隐藏参数添加到函数参数列表中。

注意：

- **仅限非静态成员函数**：静态成员函数（`static`）没有 `this` 指针，因为它们不依赖对象实例。
- **空指针问题**：通过空指针调用成员函数会导致未定义行为（除非函数不访问成员变量）。

```c++
MyClass* ptr = nullptr;
ptr->nonStaticFunc(); // 崩溃：this 是 nullptr！
```
