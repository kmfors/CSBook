## 锁

锁的种类有：

- 互斥锁：最基本的互斥锁，提供独占所有权。
- `std::recursive_mutex` 递归互斥锁：允许同一个线程多次获取同一个锁
- `std::timed_mutex`，定时互斥锁，支持带超时的锁获取操作
- `std::recursive_timed_mutex` 递归锁和定时锁的结合。
- `std::shared_mutex` 共享互斥锁 支持读写锁模式，多个读取者或一个写入者C++14

锁包装器：

- `std::lock_guard`
- `std::unique_lock`



## 一次性调用控制

```c++
#include <mutex>

std::once_flag init_flag;

void initialize() {
    std::call_once(init_flag, []() {
        // 这个函数只会执行一次
        std::cout << "Initialized once" << std::endl;
    });
}
```
