# cargo 包管理

## 项目创建

创建一个名为 `hello-cargo` 的项目：

```shell
$ cargo new hello-cargo
```

此命令生成名为 `hello-cargo` 的新目录，该目录下包含 `src` 目录与 `Cargo.toml` 文件。

- `Cargo.toml` 文件是 Rust 的清单文件，可用于保存项目及依赖项的元数据。
- `src` 目录中的 `main.rs` 文件可用于编写应用程序代码。

> [!NOTE]
>
> 注意：单独使用 `cargo new` 命令会生成样板文件 `"Hello, world"` 的项目。

---



## 编译运行

当在处于项目路径时，使用以下命令进行编译与运行，两个过程：

```shell
$ cargo run
   Compiling hello-cargo v0.1.0 (/home/user/Project/Rust/hello-cargo)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.21s
     Running `target/debug/hello-cargo`
Hello, world!
```

其效果相当于：

```shell
# 先编译，后运行
$ cargo build && ./target/debug/hello-cargo
```

> [!NOTE]
>
> 编译时默认 `debug` 模式，代码的编译速度快，但运行速度慢。原因：在 debug 模式下，Rust 编译器不会做任何的优化，为了尽快的编译完成。

若要更改编译模式可使用下面的命令：

```shell
$ cargo run --release
$ cargo build --release
```

## 代码快查

当项目扩大后，`cargo run` 和 `cargo build` 会不可避免的执行变慢，如果要使用 **更快的方式来验证代码的正确性**，可使用以下命令：

```shell
$ cargo check
	Checking hello-cargo v0.1.0 (/home/user/Project/Rust/hello-cargo)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.05s
```

> [!TIP]
>
> Rust 虽然编译速度还行，但是还是不能与 Go 语言相提并论，因为 Rust 需要做很多复杂的编译优化和语言特性解析，甚至连如何优化编译速度都成了一门学问: [优化编译速度](https://course.rs/profiling/compiler/speed-up.html)。

## 项目文件

`Cargo.toml` 和 `Cargo.lock` 是 `cargo` 的核心文件，它的所有活动均基于此二者。

- `Cargo.toml`：是 `cargo` 特有的 **项目数据描述文件**，存储了项目的所有元配置信息。如果希望 Rust 项目能够按照期望的方式进行构建、测试和运行，则必须按照合理的方式构建 `Cargo.toml`。
- `Cargo.lock`：是 `cargo` 工具根据同一项目的 `toml` 文件生成的 **项目依赖详细清单**，一般不用修改。

`Cargo.toml` 文件中一般包含两部分：

- 包配置：`[package]`
- 依赖配置：`[dependencies]`

### 包配置

一般只包含以下三部分的默认定义：

```toml
[package]
name = "world_hello"    # 项目名称
version = "0.1.0"		# 当前版本
edition = "2021"		# Rust大版本号
```

### 依赖配置

使用 `cargo` 工具的最大优势就在于，能够对该项目的各种依赖项进行方便、统一和灵活的管理。在 `Cargo.toml` 中，`[dependencies]` 一般包括：

- 基于 Rust 官方仓库 `crates.io`，官方稳定版本号，可使用 `rand` 或 `hammer` 指定
- 基于项目源代码的 git 仓库地址，通过 `URL` 来描述
- 基于本地项目的绝对路径或者相对路径，通过类 Unix 模式的路径来描述

这三种形式具体写法如下：

```toml
[dependencies]
rand = "0.3"	# 允许 0.3.x 的版本
# hammer = { version = "0.5.0"}	# 只允许 0.5.0 的版本 
color = { git = "https://github.com/bjz/color-rs" }
geometry = { path = "crates/geometry" }
```
