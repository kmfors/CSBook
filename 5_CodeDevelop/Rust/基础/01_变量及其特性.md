## 变量的声明命名与打印

1. 在 Rust 中，使用 `let` 关键字来声明变量
2. 变量的命名使用 蛇形命名法（短横线连接）
3. 使用 `println!` 对变量进行打印，它是一个 **宏调用**

```rust
// main 是 Rust 程序的入口函数，默认返回单元类型 `()`（可省略不写）
fn main() {

    // 1、在 Rust 中，使用 let 关键字来声明变量
    // 2、变量的命名使用 蛇形命名法（短横线连接） 
    let var_num = 10;

    // 3、变量的打印
    println!("val: {}", var_num);
}
```



## 变量的类型推导

- 自动推断变量的类型：整数时默认自动推断为 `i32`
- 显式指定变量的类型
- 数值后附加指定类型
- 下划线分割指定类型

```rust
fn main() {

    // 1、自动推断类型为 i32
    let a = 11;

    // 2、显式指定变量的类型为 i32
    let b: i32 = 20;

    // 3、数值后可直接附加类型
    let c = 30i32;

    // 下划线分割，仅用于可读性，不影响数值
    let d = 30_i32;
}
```



## 变量的不可变性

Rust 的核心原则之一，**所有权**：**每个值在任意时刻都有且只有一个明确的拥有者**（变量）。

**变量绑定的本质**：是将值的所有权移交给新变量，而该值之前的拥有者（如果有）会因所有权转移而失效，且无法再使用。

- 在 Rust 中，使用 `let` 声明变量的绑定，其默认行为是 **不可变**
- 定义的变量在默认情况下是不可变的，但可通过 `mut` 关键字使变量具备 **可变性**

```rust
fn main() {
    let x = 5; 
    
    x = 6; 		// x 不可变，报错！
    println!("The value of x is: {}", x);

    // y 为可变变量
    let mut y = 7;
    y = 8;		// y 可变
    println!("The value of y is: {}", y);
}
```



## 变量未使用

如果我们创建了一个变量，却不在任何地方使用它，Rust 会给出一个编译警告：

> warning: unused variable: `x`
>
> help: if this is intentional, prefix it with an underscore: `_x`

解决方法：**在变量名前添加短下划线**

```rust
fn main() {
    // 警告：提示未使用的变量
    let x = 10;
    
    // 不警告：忽略未使用的变量
    let _y = 11;
}
```



## 变量遮蔽

机制：在 Rust 中允许声明相同的变量名，在后面声明的变量会**遮蔽**掉前面声明的

作用：利用遮蔽的原理，**可以重复使用之前的变量名字**，并且不必拘泥于类型

```rust
fn main() {
    let x = 5;
    let x = x + 1; // 当前作用域下，对上面的 x 进行遮蔽
    {
        // 当前花括号作用域内，遮蔽外层的同名变量
        let x = x * 2;
        println!("The value of x in the inner scope is: {}", x);
    }
    let x = "324";

    println!("The value of x is: {}", x);
}
```



## 常量

关于常量的使用规范如下：

- 常量使用 `const` 关键字来声明，且必须**标注值的类型**
- 常量自始至终都是不可变的，不允许使用 `mut` 关键字，因为常量在编译完成后，已经确定它的值。
- 常量的命名约定是全部字母都使用大写，并使用下划线分隔单词，另外对数字字面量可插入下划线以提高可读性
- 常量可以在任意作用域内声明，仅在声明的作用域内可以访问

- 全局变量可分为公共与私有，区别在于是否可被其他文件访问
- 在实际使用中，最好将程序中用到的硬编码值都声明为常量

```rust
// 公共全局常量 - 其他文件可访问
pub const MAX_USERS: u32 = 1000;

// 私有全局常量 - 只能在当前文件访问
const MIN_USERS: u32 = 100_000;

fn main() {
    println!("MAX_USERS:{}", MAX_USERS);
    println!("MIN_USERS:{}", MIN_USERS);
}
```
