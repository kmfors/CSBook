# Rust 的数据类型

Rust 是 **静态类型** 语言，即在编译时就必须知道所有变量的类型。根据值及其使用方式，编译器通常可以推断出我们想要用的类型。

在 Rust 中，数据类型主要分为 **标量类型（Scalar Types）** 和 **复合类型（Compound Types）**，还有一些特殊类型以及自定义类型（后面介绍）。

## 标量类型

标量（scalar）类型代表一个单独的值。

1. **整数类型**:
   - 有符号整数: `i8`, `i16`, `i32`, `i64`, `i128`, `isize` (指针大小)
   - 无符号整数: `u8`, `u16`, `u32`, `u64`, `u128`, `usize` (指针大小)
   - 默认是 `i32`

2. **浮点类型**:
   - `f32` - 32 位浮点数
   - `f64` - 64 位浮点数 (默认)

3. **布尔类型**:
   - `bool` - 只能是 `true` 或 `false`

4. **字符类型**:
   - `char` - 表示一个 Unicode 标量值 (4 字节)

## 复合类型

**复合类型**（*Compound types*）可以将多个值组合成一个类型。Rust 有两个原生的复合类型：元组（tuple）和数组（array）。

### 元组类型

元组是一个将多个不同类型的值组合进一个复合类型的主要方式。**元组长度固定**：一旦声明，其长度不会增大或缩小。

```rust
// 元组变量的定义
fn main() {
    let tup: (i32, f64, u8) = (500, 6.4, 1);
}
```

`tup` 变量绑定到整个元组上，因为元组是一个单独的复合元素。为了从元组中获取单个值，可以使用模式匹配来解构元组值，像这样

```rust
fn main() {
    let tup = (500, 6.4, 1);

    let (x, y, z) = tup;

    println!("The value of y is: {y}");
}
```

也可以使用点号（`.`）后跟值的索引来直接访问所需的元组元素：

```rust
fn main() {
    let x: (i32, f64, u8) = (500, 6.4, 1);

    let five_hundred = x.0;

    let six_point_four = x.1;

    let one = x.2;
}
```

> [!NOTE]
>
> 不带任何值的元组有个特殊的名称，叫做 **单元（unit）** 元组。这种值以及对应的类型都写作 `()`，表示空值或空的返回类型。如果表达式不返回任何其他值，则会隐式返回单元值。



### 数组类型

数组类型要求组的每个元素的类型必须相同，且数组长度固定。示例如下：

```rust
fn main() {
    let a = [1, 2, 3, 4, 5];
    
    // 编写数组类型
    let a: [i32; 5] = [1, 2, 3, 4, 5];
    
    // 创建长度为5的数组，且每个元素都初始化为3
    let a = [3; 5];
    
    // 可直接使用索引下标访问元素
    let first = a[0];
    let second = a[1];
}
```

注意：当尝试用索引访问一个元素时，Rust 会检查指定的索引是否小于数组的长度。如果索引超出了数组长度，Rust 会 `panic` 掉。
